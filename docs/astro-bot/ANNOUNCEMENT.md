# Sharing the preview

Use the release link and this short announcement. Mark it experimental and state the
known limits. In the original community, use an appropriate testing/development channel
or the existing Astro Bot discussion after checking its rules and existing reports.
Avoid unrelated issues, duplicate reports and unsolicited mass mentions.

## Copyable English announcement

> I am sharing an unofficial Astro Bot testing fork based on KytyPS5 and Jetsku U59 int19.1:
> https://github.com/mauroalvare/KytyPS5-AstroBot
>
> The Windows preview reaches gameplay with PPSA21564 v01.007.000 and includes English
> setup instructions, version-locked profiles, aspect-preserving fullscreen tools and
> an optional conventional-rumble fallback. The testing kit uses the original verified
> U59 PGO release; its provenance and source are linked.
>
> This is work in progress. Busy views can fall to around 20 FPS and slow the game down;
> sky/sparse views perform much better. First-time stutters remain. Stable 60 FPS,
> correct 90/120 game speed, ultrawide behavior, HDR and full haptics are not established.
>
> If you own a supported game dump and want to help test, start with the Stable profile
> from Releases and report your hardware, exact profile/build, reproduction steps and
> complete log in this fork's issue tracker. No game files, saves or shader caches are
> included. The preview was prepared with AI coding assistance; full human source review
> and broader runtime testing are still pending. Thanks to KytyPS5 contributors and Jetsku for the base.
